ТЕХНИЧЕСКОЕ ЗАДАНИЕ
 Разработка веб-сайта «Цифровой трекер профессионального роста колледжа»

1. Цель и задачи проекта

Цель:  Создать веб-платформу для учета внеучебной и профессиональной активности студентов, автоматизации начисления баллов и публикации мероприятий колледжа.

Задачи:
- Интеграция с существующей LDAP-системой колледжа (единый вход по студенческому ID).
- Разработка личного кабинета студента с трекером баллов.
- Создание витрины мероприятий на главной странице.
- Разработка упрощенной админ-панели (для преподавателей) для управления мероприятиями и баллами.

---

 2. Функциональные требования

 2.1. Модуль аутентификации (Вход в систему)

 №  Требование 

 1  Форма входа: Логин (Студенческий ID) + Пароль. 
 2  Бэкенд проверяет учетные данные через LDAP-сервер колледжа. 
 3  После успешного входа система определяет роль: `Студент` или `Преподаватель`. 
 4  Студенческий ID автоматически подтягивается из LDAP и привязывается к профилю.   
2.2. Роль «Студент» (Личный профиль)

Главная страница (лента мероприятий):
- Список всех актуальных мероприятий (название, дата, место, максимальный балл).
- Возможность зарегистрироваться на мероприятие (кнопка «Участвую»).
- Сортировка: по дате (ближайшие сверху).

Личный профиль студента (`/profile`):
- Блок «Мой рейтинг»: Текущая сумма баллов (общая и за семестр).
- Список мероприятий студента: Таблица с колонками:
  - Название мероприятия.
  - Дата проведения.
  - Статус (Запланировано / Проведено).
  - Баллы, подтвержденные учителем выставляются после отчета, который будет прикреплен ссылкой на Telegraph.   (отображается число, если уже выставлено).


Панель управления (`/admin-panel`) – доступна только после входа через LDAP с ролью teacher.
-  Кнопка отчет, должна появляться при создание события/мероприятия, она должна заполняться ссылкой на Telegraph. 


Возможности:
1.  Создание мероприятия:
    - Форма: Название, Описание, Дата/Время, Локация, Максимальный балл.
    - Кнопка «Опубликовать» → мероприятие появляется на главной странице у студентов.
2.  Управление баллами студентов:
    - Поиск студента по Студенческому ID.
    - Выбор мероприятия из выпадающего списка.
    - Поле ввода: «Количество баллов».
    - Кнопка «Начислить» → баллы записываются в профиль студента.
3.  Редактирование/Удаление ранее созданных мероприятий.
